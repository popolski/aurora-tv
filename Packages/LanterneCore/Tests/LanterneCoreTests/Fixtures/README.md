# Jeux de données de test

Fichiers **synthétiques**, rédigés à la main pour respecter les formats décrits par
`stremio-addon-sdk` et les types de `stremio-core` (branche `development`, octobre 2026).
Ils ne sont pas des captures de serveurs réels (l'environnement de développement n'avait pas
accès à `strem.io`). Les identifiants IMDb sont publics ; aucune URL de média réel n'y figure
(domaine réservé `example.com`).

`watched_bitfield_vector.txt` a été produit avec l'implémentation de référence JavaScript
`Stremio/stremio-watched-bitfield` (voir `docs/STREMIO-API.md`).
